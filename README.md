# scc-inspector-npp (archived)

This project has been superseded by **[SCC Inspector for VS Code](https://github.com/dkneeland/scc-inspector)**, a full rewrite as a VS Code extension with Language Server Protocol support.

The VS Code version has all the features of the Notepad++ plugin plus:
- Real-time diagnostics (hover for instant feedback)
- Code lenses showing decoded captions with in/out timecode
- Outline navigation
- Theme-aware decorations
- Works in any LSP-compatible editor

This repository is kept for historical reference only.
